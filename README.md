# Android Studio / Gradle project created for a minimal app skeleton.
# This repository now contains a working Android app structure.

## Included
- Android app module
- Gradle project files
- Compose-based UI
- minimal Material 3 theme
- launch activity

## Open in Android Studio
1. Open the project folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK or Run app.

## Notes
This is a minimal Android app foundation, not a Firefox browser source tree.
